# 公开数据验证口径

复核日期：2026-10-12。公开数据用于来源内离线评估，不能代替本地高校记录。许可、可计算性、采集真实性与场景适用性分别判断。

| 来源 | 可用内容 | 限制与准入 |
|---|---|---|
| Reduce-Foodwaste | 供应方缩放日销量；独立回测已运行 | 含负值，逆变换未知；只能评估预测误差与非对称预测损失，不能模拟物理产能/批次/人民币收益 |
| university_food_waste | 原始浪费重量、价格、成本损失 | 无观测销量与备餐量；派生销量仅验演示管线，采集背景待核实 |
| Food Demand | 周级 num_orders | 不拆为日观测；周预测与静态订单策略候选，许可和语义先核验 |
| GYLAF | 必要聚合文件待审计 | 日期、聚合、单位、许可与训练重叠未核实前不能称独立校园验证；不读个人属性流水 |
| CC0零售天气 | 辅助实验候选 | CC0不证明真实采集或高校代表性；生成背景待核实 |
| 项目98条台账 | simulation流程校验 | 不计入现场样本，不证明现场效果 |

按完整时间块划分训练、调参、校准、测试；缺自然日保留未知。候选在相同点比较，融合只在调参段选权重。保存逐点预测、至少5个固定测试报告窗口、实体分组、零分母规则与不适用指标。

测试表现不佳必须保留，不更换窗口/权重掩盖。缩放销量 WAPE/sMAPE 不具有原始份数比例解释，RMSLE对负标签不适用。滚动单步允许已到达历史真值，不称多步盲预测。

物理策略只能用非负、可解释的订单/份数；销量是需求代理，剩余不等于实际浪费。容量、批次、成本比、波动参数注明假设；无营业中标签不宣称小时补餐有效。派生标签不能作为独立真实标签。
