# 项目知识与实施规划

## 业务目标

系统不以“算法复杂”为最终成果，而以经营改善为交付：降低备餐误差、减少安全售卖时段内的预计剩余、提高档口毛利，并让结果可以通过台账和日志复核。

## 技术知识

| 模块 | 知识点 | 项目应用 |
|---|---|---|
| Spring MVC | Controller、Model、路由、表单 | 服务端渲染业务页面 |
| Thymeleaf | 表达式、循环、条件、Fragment | 渲染驾驶舱、表格、状态 |
| Spring JDBC | 参数化SQL、事务 | 经营查询、预测记录、核销 |
| MySQL | 表关系、索引、事务 | 档口、菜品、经营、订单数据 |
| Java算法 | 加权平均、趋势和系数修正 | 可解释销量预测 |
| JavaScript | Fetch、DOM、异步状态 | 预测和核销局部交互 |
| ECharts | 折线、仪表、柱状、雷达图 | 经营仿真与数据面板 |
| CSS | Grid、响应式、动画、视觉变量 | 响应式经营界面 |

## 核心数据关系

```text
档口 1---N 菜品
菜品 1---N 每日经营记录
菜品 1---N 预测记录
菜品 1---N 限时优惠
优惠 1---N 预约订单
订单 1---N 核销记录
```

## 预测基线

```text
预测销量 = 近7日加权销量
         × 天气系数
         × 校历系数
         × 活动系数
         × 近期趋势系数
```

输出预测下限、中位数、上限、首批备餐量、二次补餐量和停止制作时间。后续可引入Python训练的XGBoost或LightGBM，并与当前基线比较MAE和MAPE。

## 产品使用路径

1. 驾驶舱展示当前备餐、销量、剩余和减损。
2. 从左侧“数据洞察”进入实时经营、需求分析和减损成效三个子页面。
3. 智能备餐页面运行一次明日预测，系统给出预测区间、首批和补餐建议。
4. 限时优惠页面展示安全和价格护栏。
5. 订单页面完成一次不可重复核销。
6. 经营仿真报告展示基线与策略期对比及证据链。
