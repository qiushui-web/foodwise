# 食刻有数创新创业计划书重设计方案

日期：2026年11月10日。状态：设计规划，尚未生成新版计划书、尚未对新方案作实际分页或视觉验收。

## 一、设计目标与依据

以《食刻有数_创新创业计划书_双赛融合版_20261109.docx》为内容基础，以计划书pro10为版式参考。保留可核验的项目事实、数据研究与必要表达深度，重做章节组织、图文叙事、配色及页面编排，形成适配高校食堂中小档口、兼顾大挑战杯与三创赛阅读任务的创新创业计划书。具体届次的申报字段和规则以赛事通知为准。

本方案承接最近三轮审阅：页眉页脚未充分参考模板；正文图片分布失衡；截图串联代替业务叙事；关系图过多采用方框箭头；色块面积与信息量不匹配；图前图后重复；商业章节视觉表达薄弱。此前20项检查通过仅证明相应机械规则通过，不能替代视觉质量判断。

已核对材料：当前计划书及其content_1~3.py、build_plan.py、draw_figures.py；pro10实际页面和样式；19张最新截图清单；上轮数据与建模来源及审校记录。模板对照证据在同目录style_comparison.json、style_definitions.json、template_contact.jpg。当前实际45页，正文30页，附录A截图占9页；29张图中19张为截图，非截图10张中3张是数值图。后续实施前核查源码、数据报告和截图是否又有更新。

### 关键决定

- 继续十章结构，按经营问题、产品使用、方法与证据、商业及交付推进组织。
- 素材完整保留；书内按论证需要选择。正文拟用3张截图，附录最多再选2张，其他原件留在照片目录，原DOCX不覆盖。
- 正文拟36—42页；封面摘要目录约4页，附录与来源约4—6页，总体规划44—52页，最多70页。页数是编排预算，不用扩写或图片凑页。
- 规划12张非截图图，其中7张结构或机制图、5张数据图。逐图审查，若证据不足或与表格重复则减为10—11张，不按配额强行出图。
- pro10的页眉页脚、文字层级和版面细节逐项参考；图形颜色与最新蓝色产品界面协调。先前“蓝青橙平均铺色”和“全部改成深绿”的笼统方案均不沿用。
- 本轮只交付规划文件。后续另存新版DOCX，不产生PDF，包括中间预览。

## 二、章节结构与内容权重

正文以38页为编排中值，允许自然浮动。下表中页数不包括封面、摘要、目录及附录。

| 章节与核心问题 | 二级标题设计 | 中值页数／权重 | 本轮重点 |
|---|---|---|---|
| 第一章 项目概述：为什么从高校档口备餐切入 | 1.1 一餐经营中的数量决策；1.2 服务对象与价值主张；1.3 当前基础与推进目标 | 2／5.3% | 建立项目认识，不提前展开全部功能、模型和商业细节 |
| 第二章 场景与需求：经营者真正难在哪里 | 2.1 开餐前的需求不确定性；2.2 营业中的供需变化；2.3 收餐后的复盘障碍；2.4 适用条件与首轮服务边界 | 3／7.9% | 用业务矛盾推动产品出现；政策背景压缩为有来源的短段 |

| 第六章 市场与竞争：先服务谁、替代什么 | 6.1 首轮档口筛选；6.2 替代方案与采购差异；6.3 试用渠道与市场判断 | 3／7.9% | 任务对照表替代雷达评分；不以全国高校数直接推算客户 |
| 第七章 商业模式：谁付费、为什么续用 | 7.1 服务包与付费对象；7.2 客户价值与续用条件；7.3 单位经济与服务范围 | 3／7.9% | 收费、工作量和交付责任连贯说明；两数字色块图转为简明核算表 |
| 第八章 服务交付：学生团队怎样完成首轮服务 | 8.1 准入、建档与启动；8.2 影子运行与试用复核；8.3 职责、支持与数据保护 | 3／7.9% | 与第三章区分：第三章讲档口日常使用，本章讲团队如何提供服务 |
| 第九章 财务与风险：什么条件下能够持续 | 9.1 测算假设与投入安排；9.2 利润形成与资金需求；9.3 敏感因素和风险应对 | 4／10.5% | 表格保留完整口径，图形解释盈利形成及脆弱点 |

摘要控制为一页：对象与痛点、解决方式、已有证据、商业切入、下一步目标。避免摘要把所有章节再讲一遍。

附录A仅补正文未展示且确有核验价值的操作界面，最多2张；附录B为数据指标、证据索引与必要披露；随后列参考来源。详细技术依赖、实验配置和复现材料通过项目相对路径定位，不把维护材料整段搬进正文。团队与成果只写已有证据，不设置需要补填的空白表。

## 三、图文叙事与截图选择

### 统一叙事规则

每节先提出读者需要理解的具体问题，交代项目如何处理，再选择最有效的图、截图或表格。图后解释一个关键发现、适用条件或实际操作意义，并自然引向下一问题。并非每节都必须有图，也不重复固定的五段模板。

图前文字不要逐字预告全部节点；图题只说明对象；图后不再次朗读所有数值。来源与状态用短注准确说明，较长边界集中到第五章、附录和指标口径，不在每张图下面反复出现相同免责声明。

正文示例写法（待结合源码重核）：

> 档口需要把备餐参考转成当班能够执行的数量。相同的需求估计，在库存、制作能力和剩余营业时间不同的情况下，对应的首批与补餐安排也不同。
>
> [此处接第四章核心建模图；第三章只展示经营者怎样查看、调整和确认建议。]
>
> 经营者可以核对建议依据并调整数量，实际执行与收餐盘点分别记录。后续复盘比较建议、决定和结果之间的差异，为下一餐提供参考。

方括号为本设计文件中的编辑位置说明，不能进入交付正文。若采用研究方案中的分位预测，必须在相应图与正文中标明“拟研究”，不能暗示已进入当前页面的实际运行。

### 截图方案

正文优先选备餐计划、经营记录回传、经营复盘3张。备餐计划可在完整页面与已有真实操作特写之间择一，不重复展示同一动作。三图分置于相应任务段落，不能连续组成界面展览。

正文不放登录、档口管理、使用说明等普通入口截图。余量处置通常用文字融入营业过程，确有关键操作无法通过前三张说明时，再从附录额度中择一；不因此追加一串页面。附录另一候选为首次建档操作。最终选图取决于印刷尺寸下的可读性和证据增量。

不拼接多个完整页面、不生成新界面、不篡改原截图。若完整页面信息太小，先选已有特写；确需裁切时另存衍生文件并注明对应页面，不覆盖原件、不隐藏影响理解的字段或状态。图后说明引用真实动作，截图中的本地构造数值不得当作现场成效。

## 五、配色、图形与版面语言

### 配色提案

以下为待样页检验的设计色值，不声称已从截图精确提取。主蓝沿用现有图的沉稳蓝调，与产品蓝色界面协调；弱化青色并列分类，减少橙色滥用。

| 角色 | 提案色值 | 使用边界 |
|---|---|---|
| 主色 | #285E82 | 核心业务线、研究方法或重点数值；每张图不要求都大面积出现 |
| 中性文字 | #222222／#646C74 | 图内主要文字及辅助信息；Word正文、标题、表文保持黑色 |
| 参照灰 | #9AA5AF | 历史参考、比较方法、次要路径；同时加线型或点形区分 |
| 强调橙 | #C78743 | 关键动作或需要留意的结果，不能同时把好结果和风险都用同义强调 |
| 浅色分区 | #F3F6F8 | 仅在分组确有意义时小面积使用；白底为主，无渐变与阴影 |

机制图主蓝表示主要处理路径，橙色用于人工决策节点。数据图中的颜色按方法固定映射，例如惯性参考为灰圆、固定增加为蓝灰方块、残差分位方法为主蓝菱形；不能因方法表现差而临时换色。风险阈值如需橙色，配明确线型及图例。不同图类分别定义语义，不宣称橙色同时在全书代表“人工”和“风险”。

尽量用位置、长度、线条、点形和少量图标承载信息。节点不超过两行短标签；连线避免交叉，跨区关系有方向；实际顺序可以编号，装饰序号不用。图内不写总标题、图号、总结口号和来源长段。必要坐标、单位、图例、条件和数据性质必须保留。

### 图片尺寸和页面节奏

- 大多数图按11—15.9厘米的实际阅读需要安排，数据图通常13.5—15.9厘米，核心机制图可用通栏；不要所有图片统一拉到通栏。
- 图内中文优先黑体，目标在最终插入尺寸下不小于五号附近；复杂图无法满足时先减标签、改变布局，不靠缩小字体。截图以关键字段能读为准。
- 图形PNG按最终尺寸提供足够分辨率，结构和数据图同时保存SVG与数据/代码。不把提高像素当成重设计。
- 采用“机制解释页、证据阅读页、正常论述页”交替组织；不规定每页必须一图一表，也不将多种无关图拼成大面板。
- 不连续出现三页截图；同一页通常只放一张主图。附录最多两张互不重复的截图，仍逐图独立编号，不生成拼接图片。
- 章节开头短段承接前章问题，章末给出下一步判断；删除每节的重复小结和“本章将/综上所述”式机械过渡。

## 七、内容改写边界

1. 扩充的是项目因果链、方法选择、经营取舍和服务可行性，减少的是重复截图、相同结论、空泛口号和开发过程旁白。
2. 技术栈用一张简明表说明用途。运行配置、安装命令、内部接口和本机路径不进正文；会影响可行性判断的真实技术状态必须保留。
3. 经营参谋按已实现的确定性只读解释描述，说明使用哪些数据、返回何种依据及人工操作。可选语言摘要和研究性智能体扩展分开写，不虚构自主执行能力。
4. 公开数据、仿真、本地构造台账、真实校园试用分开描述。ZHAW等旧结果不当作新分源研究结果，也不把海外研究数据当中国现场照片或校园实测。
5. 新E1—E4研究保持规划性质；旧报告不利结果如实保留。不同实验的regret/100分母不同，分图分表说明，不跨实验并列排名。
6. 财务情景不写成实际收入；贡献毛利不等于利润；真实准入、效果、付款和续费证据均不虚构。
7. 必要许可、来源、AI辅助说明、隐私与复现信息保留。没有叙事需要不新增装饰照片；确需场景素材只选可核验的中国场景，生成图须标示示意，不能冒充现场。
