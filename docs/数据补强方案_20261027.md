# 数据集补强方案：从"派生标签"到"真实食堂 + 真实干预"

**2026-10-27** · 对应建模调整建议（分层基线 + 保形校准 + 决策层）的数据侧工作

---

## 0 一句话结论

原模型的数据底子是「派生标签的 2,600 行」，撑不住大挑 B 类的追问。这一轮盘点后发现：**仓库里还躺着两份此前完全没被用起来的真实数据（京东生鲜截断需求、德国烘焙连锁的订量/售出/剩余）**，加上新补的 ZHAW 大学食堂 12 周真实实验数据，足以把"需求回测"和"因果归因"都搬到真实数据上——缺的只剩"中国高校档口的备餐-售出-剩余"这一块，那只能自己采。

## 2 新补的核心数据：ZHAW 大学食堂 12 周真实实验

- **来源**：Zenodo DOI `10.5281/zenodo.3890931`，CC BY 4.0；Egeler & Baur (2020)，ZHAW NOVANIMAL Working Paper No. 5。
- **内容**：两所大学食堂（Grüental / Vista），2017-10-02 至 2017-12-22，**60 个营业日**，26,340 笔交易，121 道菜，含价格、品类（素食/植物基/肉类/鱼类/禽类）、天气、学期周。
- **关键设计**：`Basis`（基准周）与 `Intervention`（提高素食供给周）**各 30 天交替**——这不是我们合成的断点，是**真实发生过的干预**。

已聚合出两张面板（`modeling/scripts/41_zhaw_daily_panel.py`）：

| 面板 | 行数 | 序列数 | 用途 |
|---|---|---|---|
| 日 × 食堂 × 菜品 | 585 | 226 | 菜单级分析（序列短，多数菜品只出现几天） |
| 日 × 食堂 × 品类 | 482 | 16 | **需求回测与归因的主力** |

实测事实（写入 `modeling/data/03_output/zhaw_panel_summary.json`）：

- 两食堂日销量均值 214.3 / 187.1 份，标准差 36.8 / 30.1。
- **素食占比：Grüental 31.8% → 49.5%，Vista 22.9% → 44.3%（基准周 → 干预周）**。
  干预确实改变了结构。
- **但总量几乎没变**：日均销量 Grüental 213.9 → 214.7（+0.8 份），Vista 187.2 → 187.0（−0.2 份）。
  这正是原研究"提高素食供给没有让总销量下降"的结论，**相当于一份真实数据上的“零效应”样本**——可以用来检验我们的归因方法会不会在真实数据上"测出"不该有的效果。这比合成负对照更有说服力。
- 品类序列长度差异极大：素食 56、肉类 57–59、冷热自助 60 天可用；植物基 15–16、鱼类 12、未标注 3 天，**不能单独建模**（已在测试里断言）。
- 朴素基准难度：上一周同星期预测，品类级 MAE 23.04 份、WAPE 45.1%（日均 51 份）；菜品级只有 106 个可用点，不足以训练。

**结论**：ZHAW 能支撑"真实食堂的品类级需求 + 真实干预归因"，**不能**支撑"每道菜 7 天滞后"这种特征设计——这恰好印证了上一轮的判断：把特征砍到可从短历史算出的 8 个。

## 3 三个真实缺口与补法

| 缺口 | 影响 | 补法 |
|---|---|---|
| **中国高校档口的"备餐-售出-剩余"** | 项目主场景没有真实数据 | ① 用 Reduce-Foodwaste 的 `ordered/unsold/sales` 做成本权衡的代理验证；② 按 §5 模板自采 35 天 |
| **缺货截断**：售罄日 `sold` 只是下限，不是需求 | 需求被系统性低估，报童解偏保守 | 用 FreshRetailNet 的断货标注验证修正方法（把"断货小时数"当协变量或做删失回归） |
| **中国校园日历**（考试周、寒暑假、校庆） | 现在用规则硬编码，无法验证 | 校历手工录入 + 用 ZHAW 的 `semwk`（学期周）作为"学期进程"代理变量 |

| 要回答的问题 | 用哪份数据 | 指标 |

## 5 现场采集模板（35 天起，唯一能支撑"校园减损"的证据）

按上一轮建议的 8 特征反推，每天每个菜品一行，字段尽量少：

| 字段 | 说明 | 必要性 |
|---|---|---|
| `business_date` | 营业日 | 必须 |
| `stall_id` / `dish_id` / `meal_period` | 档口、菜品、餐次 | 必须 |
| `prepared_qty` | 实际备餐量（含首锅+补餐） | 必须 |
| `sold_qty` / `discount_sold_qty` | 原价售出 / 折价售出 | 必须 |
| `leftover_qty` | 剩余处置量 | 必须 |
| `sold_out_time` | 售罄时刻（无则空） | **强烈建议**（识别截断） |
| `weather` / `exam_week` / `campus_event` | 天气、考试周、活动 | 必须 |
| `price` / `unit_cost` / `discount_price` | 成本结构 | 必须 |
| `recommendation_adopted` | 是否采纳建议、调整了多少 | 必须（算执行偏差） |

**最少 35 个营业日**（来自归因实验：噪声 3.46pp 下识别 5pp 需 35 天），且建议**两个档口并行**，一个有建议、一个照旧，否则仍然只能做描述性对照。
