# 外部效度：芬兰备餐过剩与德国烘焙连锁

**2026-10-27 · v1** · 产物：`modeling/data/03_output/external_finland.json`、`external_germany.json`

## 一句话结论

芬兰那份数据能用，而且给出了一个比我们预期大得多的杠杆：**食堂自己的干预让厨房环节过剩从 21.7 g/人降到 10.0 g/人（−54%）**。德国那份数据**不能用**——它被按门店标准化过，`ordered ≠ sales + unsold`，任何过剩率都是假的。两份都写进来，因为"不能用"也是一条要留档的结论。

---

## 一、芬兰学校食堂：154 个营业日

**数据**：`Finland_school_food_waste_2024_2025`，CC BY 4.0，Zenodo `10.5281/zenodo.20825233`。字段只有四个：`KSW`（厨房与服务环节浪费，≈备餐过剩，kg）、`PW`（餐盘浪费，kg）、`DINERS`（就餐人数）、`MENU`（25 天滚动菜单）。**没有备餐份数**，所以它能校准的是"过剩有多大、和什么相关"，不是"我们的建议量准不准"。

| 指标 | 取值 |
|---|---|
| 营业日 | 155 行（2024-08-08 至 2025-04-11） |
| 日均就餐 | 397.8 人 |
| 厨房环节浪费 | 8.06 kg/日，**20.2 g/人** |
| 餐盘浪费 | 9.08 kg/日，22.9 g/人 |
| 厨房环节占全部浪费 | **47.0%** |
| 过剩量变异系数 | 0.87 |
| 就餐人数与过剩的相关系数 | **0.166** |
| 周五 vs 周一（g/人） | **30.7 vs 15.3** |

三条可用的观察：

**1. 过剩不是"人多就多备"那么简单。** 人数与过剩量的相关系数只有 0.166——**人数解释了不到 3% 的方差**。这支持我们用"同菜品同星期中位数 + 残差分位"而不是"按人数配给"的做法。如果过剩主要随人数走，最简模型该是人均系数；数据说不是。

**2. 周内节律是真实且强烈的。** 周五 30.7 g/人，是周一 15.3 g/人的两倍。我们的基线整个建立在"同星期可比"上，这条独立数据支持这个选择。

**3. 杠杆比我们想的大。** 最后 20 天是食堂自己的干预（不是我们的模型）：厨房过剩 21.7 → 10.0 g/人（−54%），餐盘浪费 −16.8%。**这条必须先说清：这是别人家的干预效果，不是食刻有数的成效。** 它只说明一件事——这个环节有 50% 量级的空间，我们 35 天实验想检出的 5pp 不是天花板。

## 二、德国烘焙连锁：为什么不能用

**数据**：`Reduce-Foodwaste-Dataset`（Kaggle `pastry-prediction`），MIT，9 家门店 847 天、5,142 行，2021-08 至 2023-11。README 说它含 `ordered` / `unsold` / `sales` 三列——看起来正是我们要的"备餐三件套"。

**先做守恒检查，结论是不守恒：**

| 检查 | 结果 | 含义 |
|---|---|---|
| 三列齐全的行 | 3,226 | 可以检查 |
| \|ordered − sales − unsold\| 中位数 | **0.542** | 不满足 `ordered = sales + unsold` |
| 同上 95 分位 | 1.169 | 不是舍入误差 |
| `unsold` 为负的比例 | **56.1%** | 剩余量不可能为负 |
| `ordered` 为负的比例 | 49.8% | 订货量不可能为负 |
| 若硬算"过剩率" | 31.5% | **这个数没有意义** |

结论：数值被按门店标准化（z 分数）过，绝对值与比率都被破坏。**任何"德国门店过剩率 31.5%"的写法都是错的**——这正是我们把诊断过程写进脚本的原因：如果只留一个数字，早晚有人拿去引用。

能用的只有结构：

| 结构量 | 结果 |
|---|---|
| 周内节律 | 周二最高（+2.14 标准差单位）、周一几乎并列（+2.07），周日最低（−1.62），**节律存在且强** |
| 节假日效应 | 节假日销量比平日高 **+0.39 个标准差单位** |

以及一条事实性证据：**真实连锁门店确实在记录 `ordered` 与 `unsold`**。这说明我们要的字段在现实里采得到，不是我们凭空设计的表。

## 这轮新增的三条判断

1. **"备多少"不该由人头决定。** 芬兰数据里人数只解释 3% 的过剩方差；德国数据的周内节律比节假日效应强 5 倍。两边的结论一致：星期与菜单节律是主因，人数是次要变量。
2. **外部数据的价值有一半在"证明不能用"。** 德国这份如果直接算过剩率，会得到一个看起来很像结论的 31.5%。挡住它的不是眼力，是守恒检查——这跟我们在采集工具包里放校验脚本是同一个道理。
3. **效应量的量级要对齐现实。** 芬兰那个 −54% 让我们知道 5pp 的检测门槛不算高；但它是别人的干预，不能进我们的成效叙事。

## 限制

1. 芬兰只有一所学校、一所厨房、一种餐制；g/人 不能换算成份数。
2. 芬兰的 KSW 含服务环节丢弃，不等于"备餐过剩"，只能近似。
3. 德国数据被匿名化到无法做定量比较，本报告只把它当结构性证据。
4. 两份数据都不是中国高校食堂，都不能用来支持校园场景的数值结论。
