## 二、5 大原始数据集 + 功能定位

### ① `university_food_waste` — 高校食堂浪费实测（微调/回测核心）

| 项 | 内容 |
|---|---|
| **来源** | Kaggle 公开真实高校食堂浪费实测 |
| **规模** | 2,600 行 |
| **维度** | 4 档口 × 3 餐次(早/午/晚) × 4 品类(Rice/Meat/Veg/Soup)，1 学年按日实测 |
| **关键字段** | `prepare_qty` 备餐、`sold_qty` 售出、`waste_pieces` 剩余、`waste_rate` 损耗率、`Cost_Loss` 浪费成本、`Meal`/`Food_Category` |
| **功能** | ✅ **微调底座 + 高校滚动回测 + 减损金额/CO₂/水衍生指标的真实来源**，是"预测目标与效果验证"核心 |

### ② `gylaf_campus` — 中国高校真实交易流水（销量/天气校准）

| 项 | 内容 |
|---|---|
| **来源** | GitHub 开源的天津师范大学真实校园餐厅交易数据 |
| **规模** | 1,778+ 行，14 品类 × 126 天 |
| **维度** | 14 个菜品档口真实日销量 + 真实天气序列 |
| **关键字段** | 销量、档口、每日天气序列、按品类聚合统计 |
| **功能** | ✅ **① 预训练增量 + ② `waste_rate` 校准源**。用真实高校销量"反推"合理损耗率(17.5%)，替代论文中不匹配的烘焙链基准(5.6%) |

### ③ `kaggle_food_demand` — 大规模团餐/生鲜订单（预训练底座）

| 项 | 内容 |
|---|---|
| **来源** | Kaggle 公开食品需求预测竞赛数据 |
| **规模** | **456,548 行**（最大规模源） |
| **维度** | 多 SKU × 多履约中心 × 按周订单量 |
| **功能** | ✅ **预训练底座主力**。提供销量需求—天气特征映射的通用规律，用于迁移学习冷启动 |

### ④ `kaggle_cc0` — 零售+天气多商品预测（预训练增量）

| 项 | 内容 |
|---|---|
| **来源** | Kaggle CC0 公开零售需求 + 天气数据 |
| **规模** | 76,000 行 |
| **维度** | 多商品 × 日销量 × 天气 |
| **功能** | ✅ **预训练增量**。扩展天气/节假日特征多样性，补足需求预测的天气敏感性 |

### ⑤ `reduce_foodwaste` — 行业减损基准（基准校准参考）

| 项 | 内容 |
|---|---|
| **来源** | Kaggle 公开"减少食物浪费"竞赛数据 |
| **功能** | ✅ **作为减损目标与行业基准参考**。注：其内嵌 waste_rate=5.6% 偏低、属工业链场景，经校准已被 ②gylaf 的 17.5% 替代，仅作对照 |

## 三、清洗产物：02_processed（直接能用的建模输入）

| 文件 | 内容 / 用途 |
|---|---|
| `pretrain_all.parquet` + sample500 | **53.4 万行** 合并底座（genpack 456k + gylaf 1.7k + cc0 76k），log 变换对齐量级 → 训练 LGBM 预训练模型 |
| `cc0_weather.parquet` + sample500 | CC0 清洗子集，扩大天气特征覆盖 |
| `finetune_uwaste.parquet` + metadata.csv | **2,600 行高校微调/回测特征**（含 24 个特征：lag、滚动均值、天气、节假日、价格促销等），模型评估的最终数据 |

**特征 schema 示例（finetune_uwaste）**：
`day_of_week, is_weekend, is_exam_week, has_campus_event, weather_code, temp_max_c, category_id, price, unit_cost, discount_rate, promotion_flag, lag_1/2/3/7_sold, rolling_mean_3/7, rolling_std_7, same_dow_last_4w_mean, is_school_holiday, is_state_holiday, special_day, comp_price_ratio, recent_trend_3d, sold_qty, prepare_qty, waste_pieces, waste_rate`

## 四、注入 Java 的 9 个建模产物（src/main/resources/modeling/）

## 五、三个数据集"功能分工"一句话总结

```
③genpack  → 大规模预训练底座（学通用销量规律）
②gylaf    → 真实高校销量 + 校准 waste_rate（中国国情校正）
①uwaste   → 高校浪费实测（微调+回测+减损指标最终验证）
④cc0 / ⑤reduce → 预训练增量 & 行业基准对照
```
