# 样式配置与三轮审校记录

交付日期：2026年11月9日。对象：食刻有数创新创业计划书·双赛融合版。

## 版式依据

实际提取计划书pro10的段落、页面及表格属性后，采用A4；页边距上2.5、下2.3、左2.7、右2.4厘米；页眉页脚距边界1.2厘米。正文宋体12磅、1.5倍行距，非加粗；章标题黑体18磅、二级标题黑体16磅并编号；图表题黑体10.5磅；表文宋体9.5磅、1.12倍行距、水平垂直居中。表格无底色、无竖线，采用三线表。保持页眉横线、正文页码和目录导航。未照搬模板异常缩进或蓝色三级标题。

## 第一轮：事实与结构

以最新源码、数据目录及建模方案为主，核对相关会话和三份历史稿。重构为十章，先说明场景与产品，再解释数据、建模和验证，随后展开市场、商业、交付、财务及实施。历史稿仅吸收有效论证，不恢复未经证实的成绩或宣传性数据。区分公开回测、情景仿真、本地构造验收与未来校园试用；E1—E4新实验写为研究计划。技术栈按依赖和实现更新；经营参谋为确定性只读解释，可选适配不写成已完成的开放智能体。

纠正旧稿仿真汇总口径：由冻结明细重算并核对240次仿真均值；说明两类实验的regret/100分母不同，不跨实验比较。保留模型未稳定胜出及缺货风险。财务全部标记为规划情景，校验收入、成本、利润关系。

## 第二轮：图文表达

19张最新截图原样嵌入，正文5张、附录14张；保留原始二进制，不拼接、不伪造、不生成重绘。10张新图由代码生成，结构关系和数据可追溯；说明移至图下，不添加装饰性真人和宣传照片。读取ciyuanshen-image规范后，本轮因图形均要求准确数据或精确关系，采用结构化绘图，没有调用生图API。

统一图表按章编号、正文引用和图下解释。减少重复总结及开发过程叙述，保留必要技术边界、来源、许可和AI辅助说明。附录提供现有界面与证据口径，不附需要补填的空白调研表。

## 第三轮：实际Word分页与定稿

使用Microsoft Word实际排版并逐页导出PNG检查，未生成PDF。前轮检查覆盖所有页面联系表及关键页放大；最终修订后复核第四章末页与第五章首页。修复短表断页、图题与说明分离、技术图多余白边、重复段落产生的稀疏尾页；重新回填目录并保存。正文粗细以Word字体属性核对，确认宋体12磅且Bold=0。

最终实测45页，十章正文，19表，29图（19张原始截图与10张重绘图），56条目录记录。20项自动检查全部通过：编号、占位、目录、目录文件类型、无PDF、截图一致性、表格样式、数字核验、页数、拆行、图题/说明位置及字体等。完整结果见qa_final.json和word_layout_audit.json。

## 使用范围与限制

本版为大挑战杯和三创赛共用基础文稿；具体届次的申报表、身份字段、匿名要求及提交规则仍须按赛事通知核对。未虚构团队身份、校园授权、经营收益或付费案例。本轮未重新运行完整模型训练及现场实验，使用冻结结果并核验其汇总，不代表已验证现场经营成效，也不承诺获奖。
