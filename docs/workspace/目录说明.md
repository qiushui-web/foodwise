# 工作区目录说明

## 五类主目录

代码与运行资料归入“项目代码”，产品与经营方案归入“计划书”，展示资料归入“PPT”，原始数据与建模输入归入“数据来源”，软件著作权相关材料归入“软著资料”。根目录的 README 提供导航，AGENTS 记录维护约定。

## 项目代码分布

| 目录 | 用途 |
|---|---|
| src | 后端、接口、运行配置与随应用发布的资源 |
| frontend | 前端页面、交互与浏览器测试 |
| modeling | 数据处理、模型、实验与验证 |
| deploy | 部署配置 |
| scripts | 项目运行和维护工具 |
| docs | 产品、架构、研究、验证与维护资料 |
| assets | 工程使用的素材 |
| data | 项目运行和研究所需数据 |
| output | 工具输出资料 |
| build、.gradle 等 | 构建和本地运行产生的文件 |

运行目录、Git 元数据和依赖目录按现有工具结构维护，资料整理围绕内容用途归位。

## 版本与引用

现用计划书和 PPT 在对应“版本”目录中直接可见；旧稿与阶段资料按类别集中为 ZIP 归档。当前生成模板直接保存在生成目录，路径随移动更新。原始数据统一通过数据目录索引查找，标准表按来源独立维护。

文件名采用“项目_内容_日期”；资料说明以用户操作、项目应用和验证方法组织。历史原件、来源标题、许可与申请专用字段保留原始信息。

[目录调整记录](目录调整记录_20261109.json)保留前一阶段位置变化；后续压平与缓存清理以 [清理迁移记录](清理迁移记录_20261109.json) 为准，记录归档位置、包内原路径和逐文件校验值。Word/PPT 正文保持原样。

当前归档分为四份：`计划书/历史资料.zip`、`PPT/历史资料.zip`、`软著资料/核验快照_20261016.zip`、`项目代码/docs/archive/历史工作资料_20261109.zip`。归档按工作区原相对路径保存。解压到单独目录查阅；需要恢复时按迁移记录选择文件，避免覆盖现用版本。
